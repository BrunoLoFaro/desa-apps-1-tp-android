# XploreNow - Aplicación de Actividades y Experiencias Turísticas 🌍✈️

**XploreNow** es una plataforma móvil diseñada para conectar viajeros con las mejores experiencias locales, tours y excursiones. Este repositorio contiene el desarrollo de la **Aplicación Android Nativa** (escrita en Java) para el Trabajo Práctico Obligatorio.

## 📋 Descripción del Proyecto
La aplicación permite a los usuarios buscar y reservar actividades turísticas de manera sencilla, integrándose con un sistema central que gestiona disponibilidad, precios y guías en tiempo real. El objetivo principal es digitalizar la experiencia del viajero, ofreciendo una interfaz moderna orientada al turismo experiencial.

## 🚀 Funcionalidades (Android Nativo)
*   **Exploración de Destinos:** Visualización de actividades y experiencias disponibles.
*   **Detalle de Actividades:** Información completa sobre tours, excursiones y visitas guiadas.
*   **Integración API REST:** Consumo de datos actualizados sobre cupos y precios.
*   **Arquitectura:** Implementación en Java siguiendo las buenas prácticas de desarrollo Android.

## 🛠️ Stack Tecnológico
*   **Lenguaje:** Java ☕
*   **Entorno de Desarrollo:** Android Studio Jellyfish / Koala
*   **Gestión de Dependencias:** Gradle (Kotlin DSL o Groovy)
*   **Red:** Retrofit 2 para el consumo de la API REST.
*   **Serialización:** Moshi / Gson.
*   **Integración Continua:** GitHub Actions (Build & Test).

## 📂 Estructura del Repositorio
*   `/app`: Código fuente de la aplicación Android.
*   `.github/workflows`: Configuración de CI/CD para compilación automática.
*   `.gitignore`: Configuración para excluir archivos temporales de IDE y Gradle.
